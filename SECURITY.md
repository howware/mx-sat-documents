# Security and privacy

## Reporting a problem

If you find a vulnerability, or a case where `mxsat` **lets personal data through** in its output, report it
**privately**: **Security → Report a vulnerability** in this repository, or
https://github.com/howware/mx-sat-documents/security/advisories/new.

Describe it **without real data**: the command and `mxsat version`, which output field held the value, its
**kind** (RFC, name, postal code…) and its **masked shape** (`XXXX999999XX9`).

**Never post** invoices, receipts, outputs, stores or screenshots with real data in issues, pull requests or
discussions.

## What to expect

A personal project maintained in spare time: answers come as soon as possible, without a guaranteed deadline.
Personal-data leaks take priority over any other change.

## Supported versions

Only the latest version on `main`.
